# Decision Log

This log records important project choices as they are made.

## DEC-001 — Browser-based delivery

- **Status:** Accepted
- **Decision:** Build the simulator as a browser-based application.
- **Reason:** It provides a low-friction demonstration and training format without requiring trainees to install a desktop application.

## DEC-002 — Scenario-specific training model

- **Status:** Accepted
- **Decision:** Model an explicitly fictional, reviewable topology instead of presenting a universal UPS switching sequence.
- **Reason:** Real procedures vary across equipment and sites. A bounded scenario supports learning while keeping the project’s limitations visible.

## DEC-003 — Incremental documentation

- **Status:** Accepted
- **Decision:** Update requirements, design notes, tests, screenshots, and lessons learned alongside each development phase.
- **Reason:** The repository is both a training-tool project and a Fun Weekend Project portfolio artifact.

## DEC-004 — Implementation stack
